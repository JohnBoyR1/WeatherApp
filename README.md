# Weather App

A web-based weather application developed using **JavaScript, HTML, and CSS** that allows users to search for live weather information by **country and city**.

The application retrieves current weather data from an external weather API and presents the information through a simple and user-friendly interface.

## Features

- Search for weather information by country and city
- Retrieve live weather data from an external API
- Display the current temperature
- Display current weather conditions
- Dynamically update weather information based on the user's search
- Process and display JSON data returned by the API
- Responsive web interface built with HTML and CSS

## Technologies Used

- **JavaScript**
- **HTML5**
- **CSS3**
- **REST API**
- **JSON**
- **Git & GitHub**

## How It Works

The application takes a location entered by the user and sends a request to a live weather API.

The returned JSON weather data is processed using JavaScript and the relevant information is displayed dynamically in the browser, including the current temperature and weather conditions for the selected location.

## Running the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

> **Note:** An internet connection is required to retrieve live weather information from the external API.
